# jianpu-md 规范 v0.2

> 目标：一份纯文本（`.md` / `.txt`）既是**人可读的乐谱源码**，也是**渲染器/播放器的唯一输入**。
> 与 Markdown 天然兼容：前置元数据用 YAML front matter，乐谱行就是普通文本行，可直接进 git。
>
> **v0.2 起同时接受 JPW-ABC 写法**（JP-Word 4.0 手册第 6 章），对照与取舍见
> [`03-JPW-ABC-对照与兼容.md`](./03-JPW-ABC-对照与兼容.md)。本文件仍是权威语法表；
> 凡是本文与 03 冲突，以本文为准，03 只解释「为什么和 JPW 不一样」。

---

## 1. 文件结构

```markdown
---
title: 小星星
subtitle: 二胡入门练习
composer: 莫扎特
key: 1=C
time: 2/4
tempo: 96
tuning: 1-5 弦（内 D / 外 A）
---

% 段落名（渲染为段标题）
| 1 1 | 5 5 | 6 6 | 5 - |
L: 一 闪 一 闪 亮 晶 晶
```

| 部位 | 作用 |
|---|---|
| `--- ... ---` | 元数据（可省略） |
| `%` / `%%` / `//` 开头 | 段落标题，强制换行 |
| `L:` 或 `L：` | 歌词行，附着到**上一条**乐谱行 |
| 空行 | 忽略（换行由排版器自动决定） |
| 其余行 | 乐谱行 |

**元数据键**：`title` `subtitle` `composer` `lyricist` `arranger` `key` `time` `tempo` `tuning` `instrument` `copyright`。
正文里也允许写 `key: 1=G` 这类行覆盖元数据（用于中途转调）。

## 2. 音符语法

一个音符 token 的完整形态：

```
[变音] 数字 [八度/减时线/增时线/附点 的任意顺序组合] [@记号 ...]
```

**两种写法都吃**（v0.2）：

| 要素 | jianpu-md | JPW-ABC | 说明 |
|---|---|---|---|
| 减时线 | `1/` `1//` | `1_` `1__` | 等价，可混写 |
| 变音 | `#4` `4#` | `#4` | 前置是推荐写法 |
| 倚音 | `^{6 2}` | `{6,2}` | 都是 16 分前倚音 |
| 技法 | `@dun` `@w` | `{DunYin}` `{BoYin}` | 落到同一张符号表，见 §3 |
| 增时线粘连 | `5 - 3` | `5-3` | `-` 紧贴后续音也能解析 |

**后缀顺序不敏感**（v0.1.1 起）：`1'_.`、`1'._`、`1_.'`、`6._` 全部等价。
手写稿转文本时顺序没人能统一，解析器不该在这里挑刺。

| 语义 | 写法 | 例 |
|---|---|---|
| 音高 | `1`–`7` | `1` = do |
| 休止 | `0` | `0 0` |
| 噪音/打击 | `x` | `x x` |
| 升 / 降 / 还原 | `#` `b` `n` 前缀 | `#4` `b3` `n5` |
| 高八度 / 低八度 | `'` / `,` 后缀，可叠加 | `1'` `1''` `5,` `5,,` |
| 八分 / 十六分 / 三十二分 | `/` `//` `///`（= 减时线） | `3/` `3//` |
| 同上，JPW-ABC 写法 | `_` `__` `___` | `3_` `3__` |
| 二分 / 全音符 | `-` 后缀或独立写出（= 增时线） | `5-` 或 `5 -`、`5 - - -` |
| 附点 | `.` 后缀（可双附点） | `5.` `5/.` `5._` |
| 延音线 | `~` 独立 token（连接前一个音） | `5 ~ 5` |
| 圆滑线/连弓 | `(` … `)` 包住若干音 | `(4 3)` |
| 小节线 | `|` | `| 1 1 |` |
| 反复起止 | `\|:` `:\|` | `\|: 1 2 :\|` |
| 终止线 | `\|]` 或 `\|\|` | `1 - \|\|` |

> 时值 = `1/2^减时线数 + 增时线数`，再乘附点系数 `1 + (1 - 0.5^附点数)`。
> 变音记号是**音符自身的属性**，永远不从调号推导：`1=D` 里写 `7` 就是自然 7，
> 要降七必须显式写 `b7`。（按调式自动补 ♭ 是最容易埋的雷。）

### 2.1 小节号

`// 35` 这种「只有 `//` + 数字」的行是**小节号指令**：下一小节编号为 35，其后顺延。

```
// 33
| 1/ 2/ | | 3/ 4/ |
```

- 中间的空小节（`| |`）**会被保留成一个小节**（拍数 0），不会静默丢弃 —— 否则它后面的
  小节号全部前移，「第 35 小节不对」这种反馈就没法对。空小节会告警，正常休止请写 `0 0`。
- 小节号由 `parser` 一次性分配给全曲（含空小节），不信数组下标。

## 3. 演奏记号（`@` 后缀，作用于**本音**）

| 记号 | 渲染 | 含义 |
|---|---|---|
| `@la` | ㄇ | 拉弓（出弓） |
| `@tui` | ∨ | 推弓（入弓） |
| `@lian` | ⌒ | 连弓 |
| `@dun` | ▼ | 顿弓 |
| `@0` `@1` `@2` `@3` `@4` | 0 一 二 三 四 | 空弦 / 食 / 中 / 无名 / 小指 |
| `@nei` `@wai` | 内 外 | 内弦 / 外弦 |
| `@chuo` `@zhu` | ↗ ↘ | 绰音（上滑）/ 注音（下滑） |
| `@rou` | 吟 | 揉弦（吟弦） |
| `@tr` | tr | 打弦（颤音） |
| `@w` `@bw` | ⌣ ⌢ | 上波音 / 下波音 |
| `@o` | ○ | 泛音 |
| `@v` | v | 换气 |
| `@>` | > | 重音 |

可叠加：`5@la@0` = 拉弓 + 空弦。

**v0.2 起三种名字等价**：`@dun` ≡ `{DunYin}` ≡ `{顿音}`。
拼音名与中文名走同一张别名表（`MARK_ALIAS`），查不到的记号给「未知记号」告警，**不静默丢弃**——写错一个记号却什么都没发生，是最难查的错。

| 拼音（JPW-ABC） | 中文 | 归一化 |
|---|---|---|
| `DunYin` | 顿音 | `dun` |
| `BoYin` / `YanYin` | 波音 / 延音 | `w` / `=` |
| `ChanYin` / `DaYin` | 颤音 / 打音 | `tr` |
| `FanYin` / `RouYin` | 泛音 / 揉弦 | `o` / `rou` |
| `ChuoYin` / `ZhuYin` | 绰音 / 注音 | `chuo` / `zhu` |
| `LaGong` / `TuiGong` | 拉弓 / 推弓 | `la` / `tui` |

记号书写位置也放宽：`7__{DunYin}`（贴在前音后）和 `{YanYin}2-`（写在小节开头、作用于后音）都能解析。

> 设计取舍：**用 `@` 前缀而不是 `~` 之类的符号**，因为 ASCII 里能表达"记号"的字符就那么多，`@` 语义清晰、可无限扩展、不影响音符本身的解析。

## 4. 歌词

```markdown
| 1 1 | 5 5 | 6 6 | 5 - |
L: 一 闪 一 闪 亮 晶 晶
```

- 按**发声音符**（数字 1–7，不含 `0`）依次对齐，一字一音。
- 一个字跨多个音符用 `-` 占位：`L: 好 - 好 学 习`。
- 中文可不打空格，渲染器按字自动切分。
- 一个字对应多个音符时，若字数与音符数不等，渲染器给告警而不是硬撑。

## 5. 排版约定（实现约束，别随手改）

1. **x 坐标按实际拍值比例分配，不在小节内均分。** 均分会让密集十六分糊成一团。
   但纯比例也不行（十六分 0.25 拍 ≈ 8px，数字叠字），所以每个时值档给下限：
   八分 0.62 槽、十六分 0.55、三十二分 0.50，更短 0.48。
2. **减时线按拍分组**：一拍一组，组内主横线贯通，**拍界必须断开**。
   简谱的梁是「时值说明」，跨拍的梁会把节奏读错。6/8 等复合拍按 3 个八分一组（1.5 拍）。
3. **第二层及以下的梁只连「减时线数 ≥ 该层」的连续子段**：
   一拍里 `八分 十六分 十六分` 时，第二条横线只盖住那两个十六分，不能落到八分下面。
4. 休止符、四分及更长的音截断梁。
5. 长音（含增时线）左对齐占位、增时线跟在音符右侧；普通音符在单元格居中。
6. 连音弧端点吸附到音符 bbox 上/下方，不写死坐标（字号或行距一改就废）。
7. 单行小节数不固定为 4：按内容宽度自适应换行，末行不强行拉伸（缩放 >1.55 就放弃拉伸）。

## 6. 校验规则（渲染器必须给的警告）

1. 小节内时值之和 ≠ 拍号 → `第 35 小节拍数为 3，应为 2`（用**显式小节号**，不用下标）。
2. 空小节 → `第 N 小节是空小节（本声部休止请写 0 0）`。
3. 歌词字数 ≠ 发声音符数 → `歌词 14 字 / 音符 13 个`。
4. 未知 token / 未闭合的 `(` / 未闭合的连弓 → 语法错误定位到字符位置。

> 打谱软件好不好用，一半在这个"错在哪一行哪一拍"的反馈上。

## 8. 与 JPW-ABC（JP-Word 4.0）的互操作

合唱/民乐圈里现成的文本记谱事实标准是 JPW-ABC，能直接吃它的写法就少一道转换。
本项目已兼容的部分：

| JPW-ABC | jianpu-md | 说明 |
|---|---|---|
| `1_` `1__` | `1/` `1//` | 减时线两种写法等价 |
| `1'` `1,` | 同 | 八度 |
| `1.` | 同 | 附点 |
| `1-` / `1 -` | 同 | 增时线（每个 `-` 加一拍） |
| `b7` `#4` | 同 | 变音，且都是**音符属性**，不从调式推导 |
| `(6.5)` | `(6. 5)` | 连弓弧：JPW-ABC 括号内可以不留空格，本项目的 tokenizer 要求**
音符之间有分隔**，所以需要加空格 |
| `\|` `\|:` `:\|` `\|]` `$` | 同（`$` 忽略） | 小节线 / 反复 / 终止 |
| `.Voice` / `.Title` 节 | 不需要 | 本项目用 front matter + 正文直接写谱 |
| `//` 行注释 | **冲突，不支持** | 见下 |

**`//` 不能做注释**：本项目里 `/` 是减时线，`1//` 就是十六分音符。
`// 35` 这一种（`//` + 纯数字）被占用为「小节号指令」，其余 `//` 开头的行仍是段落标题。
要注释请用 `;` 或 `--`。

**v0.2 起不再需要手工归一化**：减时线 `_`、技法 `{DunYin}`、倚音 `{6,2}`、增时线粘连 `5-3`、
房子 `|[1.`、段落 `$`、标准文字 `"…"`、行内拍号，解析器直接吃（实现见 `src/parser.ts` 的 `preprocessJpw`）。

仍然要手工处理的只有**文件外壳**：

```
.Options / .Fonts / .Page 节   → 直接删掉（排版参数不进谱面）
.Title 节                      → YAML front matter
KeyAndMeters = {1=D,2/4}       → key: 1=D / time: 2/4
.Voice 节                      → 删掉节名行，正文就是乐谱行
.Words 节                      → 每行改成紧跟乐谱行的 L: 行
```

完整对照、逐项取舍、以及「哪些故意不实现」见 [`03-JPW-ABC-对照与兼容.md`](./03-JPW-ABC-对照与兼容.md)。
