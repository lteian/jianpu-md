# 简谱打谱生态调研（2026-10）

> 结论先说：简谱打谱软件**不是没有**，而是"能打的不好用，好用的不开源，开源的只做渲染不做播放"。
> 真正值得抄作业的是 3 个：`jianpu-ly`（语法 + 二胡符号）、`番茄简谱`（中文脚本规范）、`Dolce/jpeditor`（完整产品形态）。

## 二、商业/闭源

- **作曲大师 / QuickMake**：简谱+五线谱互转，国内老牌，闭源收费。
- **TT 作曲家**：文本输入式简谱，1999–2001，已停更。
- **简谱乐章**：作者已停止分发，只剩免费版。
- **XunScore（迅谱）**：闭源，Linux 版免费，其他平台收费且需国内银行卡。
- **S-Music**：Windows 免费软件。
- **Guitar Pro 8.1**：2023 年新增 Jianpu 记谱。
- **DomiSol / 来音 / 紫葡萄 等 App**：手机端简谱，教育和 K 歌场景为主。
- **Dorico / Finale / Sibelius**：均**没有**简谱（Dorico 论坛明确表示暂时不做；Sibelius 曾有第三方简谱插件）。

## 三、规范层面

1. **国家标准在起草**：文化和旅游部提出、国标委立项的《**音乐简谱记谱规范 第 1 部分：歌曲**》已完成征求意见稿（中国文联/中国音协渠道公开征求意见）。目前**尚无生效的简谱国标**，行业惯例靠教材（李重光《简谱乐理》一类）。
2. **简谱记谱法本体**（无争议的硬规则）：
   - 音高：`1–7` 首调唱名；高八度音符上方加 `·`，低八度下方加 `·`，两点为两个八度。
   - 音长：四分音符为基准（不加记号）；**增时线** `—` 写在音符右侧，每条 +1 拍；**减时线** 写在音符下方，每条减半（八分/十六分/三十二分）；**附点** `·` 右侧，延长原值一半（可双附点）。
   - 休止：`0`，同样用增时线/减时线/附点。
   - 变音：`♯ ♭ ♮` 写在数字左上。
   - 其他：小节线 `|`、终止线 `‖`、连谱号、延音线/圆滑线 `⌒`、连音符（三连音）、换气 `v`、顿音 `▼`、保持音 `-`、重音 `>`、力度 `f p mf mp` + 渐强渐弱、反复 `‖: :‖`、反复跳跃记号（房子）、`D.C./D.S./Fine/Coda`。
3. **二胡专用符号**（这套是我们必须支持的差异化点，来源：刘天华体系《二胡常用术语与符号》）：
   - 弓法：`ㄇ` 或 `→` = **拉弓（出弓）**；`∨` 或 `←` = **推弓（入弓）**；`⌒` 连弓（一弓）；`▼` 顿弓；`>` 重弓。
   - 指法：`一 二 三 四`（食/中/无名/小指），`0` 空弦（散音）。
   - 弦序：`内`/`外`（内弦、外弦）。
   - 左手技巧：`tr` 打弦（颤音）、`丁` 单打音、`卜/↗` 绰音（上滑）、`シ/↘` 注音（下滑）、`ラ` 吟弦（揉弦）、`○` 泛音。
   - 定弦：`1=D` 15 弦、`1=G` 52 弦、`1=F` 63 弦、`1=C` 26 弦、`1=♭B` 37 弦。

## 四、对我们要做的事的启示

1. **纯文本 + 渲染器**这条路被 jianpu-ly 和番茄简谱验证过 20 年了，方向没问题；缺的是"**中文友好 + 浏览器内 + 能播二胡**"。
2. jianpu-ly 的语法是**事实标准**，我们应该尽量兼容它的写法（`'`/`,` 表八度、`q/s` 或 `\` 表时值、`@` 类记号），降低用户迁移成本。
3. **二胡符号是护城河**：上面列的开源项目里，只有 jianpu-ly 认真做了二胡记号，且它要求装 Python + LilyPond（约 200MB）才能出图。我们做一个"双击 HTML 就能用"的，直接降维打击。
4. 版权与许可：如果将来要抄代码，`dolce/jpeditor` 是 MIT（安全），`jianpu-ly` 是 GPL（只能看思路，不能抄代码进闭源项目）。
